# Cyber Lab IN Public Design System

Date: July 15, 2026

## Direction

The public website uses an enterprise editorial system inspired by the hierarchy and content density of large technology organisations. It does not copy Cisco branding, graphics, copy or source code.

## Core Tokens

- Primary ink: `#101820`
- Cyber Lab IN blue: `#0B65A3`
- Dark blue: `#084F80`
- Cyan accent: `#007FA8`
- White: `#FFFFFF`
- Light surface: `#F4F7F9`
- Border: `#D9E1E7`
- Muted text: `#52616B`
- Dark contrast section: `#101820`

## Typography

- Inter is the single public type family.
- Editorial headings use controlled responsive sizes and compact line height.
- Body copy is kept between 60 and 75 characters where practical.
- Labels are compact and descriptive, without decorative gradient text.

## Layout

- Main content width: 1280px.
- Reading width: 760px.
- Sections use 64px to 112px vertical spacing depending on hierarchy.
- Border radius is restrained: 0 to 12px for most public components.
- Shadows are reserved for overlays and elevated navigation only.

## Interaction

- Mega menus open through accessible buttons and close with Escape.
- Mobile navigation uses accordions.
- Focus rings are visible and meet contrast expectations.
- Motion is limited to short menu, underline and arrow transitions.
- Reduced-motion preferences disable non-essential transitions.
